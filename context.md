Datasport Dashboard — Redesign Prototype
Goal
Frontend proof of concept for a redesigned Datasport platform.
Datasport is a Polish running event registration platform.
The prototype covers three views: dashboard, event list, and event detail page.
Brand identity is preserved — white background, red accents.

Problems With the Original Site
Dashboard

No visible button or shortcut to register for a race after login
Training feed from other users dominates the view, pushing personal content down
No visual hierarchy — every section looks identical, hard to scan
Navbar blends into the background and is easy to miss

Event list

Cards are too tall on mobile, causing excessive scrolling
Typography and shadows feel dated

Event detail page

Hero section has too much empty space on desktop
The main "Register" button does not stand out enough
On mobile the hero is too tall, requiring scroll before reaching key information


Evaluation Criteria

Is the primary CTA (register for a race) immediately visible on the dashboard?
Does the dashboard lead with the user's upcoming races and tickets?
Is the event list comfortable to browse on mobile (375px viewport)?
On the event detail page, does the "Register" button stand out clearly?
Is the layout clean without excessive borders, gradients or decoration?
Is red used consistently as a functional accent, not just decoration?
